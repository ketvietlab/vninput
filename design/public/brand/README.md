# VNInput logo

`vninput-logo.png` — original generated PNG, transparent background, 1254 × 1254.

Created with the built-in image_gen tool on 2026-09-30. The source output was copied intact into this project. It is a raster asset, not an SVG/vector master. The mockup uses its alpha as a CSS mask with the Két accent color, so Light/Dark retains the same geometry and semantic color.

## Final prompt

Use case: logo-brand. Create ONE polished, original logo symbol for VNInput, a lightweight Vietnamese keyboard input application for macOS, Windows, and Linux. A minimal geometric V monogram with a small, clear Vietnamese acute-accent stroke rising above the upper right. Integrate a subtle keyboard-key idea into the silhouette, without drawing a full keyboard. Precise confident geometry, slightly softened corners, strong negative space, flat vector-like finish. Compact square 1:1 composition, centered mark filling about 85 percent of the canvas. Solid indigo #4F5ED0 matching the Két Design System accent; use transparent negative space, no extra colors. Must remain recognizable at 24x24 pixels and look professional in a restrained desktop settings window. Output a single isolated symbol on a genuinely transparent background. No wordmark, no text other than the implied V, no tagline, no presentation sheet, no variations, no enclosing mockup, no gradient, no shadows, no 3D, no texture, no decorative sparkles. Crisp clean edges, production-quality brand mark.
